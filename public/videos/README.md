# Vídeos oficiais Ducha Elitte

A página **Como usar** usa dois vídeos produzidos com voz feminina natural do HeyGen,
hospedados em uma **Vercel Blob pública** da própria Ducha Elitte. Isso garante URLs
persistentes, sem depender de links temporários e sem colocar arquivos binários
dentro do repositório GitHub.

Vídeos publicados:

- [Guia rápido com narração humanizada (32,08s)](https://zbpfvd9tctfhm3g8.public.blob.vercel-storage.com/ducha-elitte/treinamento/ducha_elitte_guia_rapido_todas_abas.mp4)
- [Treinamento completo com narração humanizada (108,49s)](https://zbpfvd9tctfhm3g8.public.blob.vercel-storage.com/ducha-elitte/treinamento/ducha_elitte_treinamento_abas_suporte_chamados.mp4)

Os dois links estão incorporados diretamente na tela
`src/app/(dashboard)/como-usar/page.tsx`, com controles para desktop e mobile.

Vídeos anteriores mantidos apenas como fontes históricas; não são mais
incorporados na seção principal. O vídeo adicional definido por um administrador
em Configurações continua disponível de forma independente.

Não foi necessário alterar banco de dados, credenciais, autenticação ou
configurações de multiempresa.
